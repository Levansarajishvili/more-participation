# პროექტის კონტექსტი — „მეტი ჩართულობა“

## 1. ორგანიზაცია

- **სრული სახელი:** მეტი ჩართულობა განვითარებისა და სოციალური ცვლილებებისთვის
- **სლოგანი:** „არასოდეს მისცე უფლება ფიზიკურ შეზღუდვებს შენი განვითარება შეაფერხოს!“
- **მისია:** შშმ პირების აქტიური ჩართვა საზოგადოებრივ ცხოვრებაში; პიროვნული და პროფესიული განვითარების, თვითრეალიზაციისა და სოციალური ცვლილებების მხარდაჭერა.
- **სამი მიმართულება:** ჩართულობა · განვითარება · სოციალური ცვლილება
- **ღირებულებები:** თავდაჯერებულობა, კრეატიულობა, გაბედულება, შეუპოვრობა, ცნობისმოყვარეობა, ზრდაზე ორიენტაცია
- **ბრენდის ხასიათი:** თავდაჯერებული, კრეატიული, გაბედული, ზრდაზე ორიენტირებული. არა — მოწყალე, პასიური, საქველმოქმედო.
- **ძირითადი აუდიტორია:** შშმ პირები და მათი ოჯახები; მეორეული — მოხალისეები, პარტნიორი კომპანიები, დონორები, მედია.

## 4. ლოგო

**საბოლოო ლოგო — „ერთად · სინერგია“.** გამოიყენება საიტის შვიდივე გვერდზე.

- საფუძველი — ვარიანტი „ერთად“: ხუთი ფიგურა მზის გარშემო, ფერხულის სიმეტრიით.
- შესრულება: 3D ეფექტი და ფაზლის ელემენტები; ნაწილები ერთმანეთს ოდნავ დაშორებულია, რომ 3D უფრო მკვეთრად იკითხებოდეს.
- სინერგია: ყოველი ნაწილიდან ენერგია ცენტრისკენ მიედინება; ცენტრალურ ჰაბში — თეთრი ზრდის სპირალი.
- უარყოფილი შესრულება: LEGO-ბლოკები.
- დანარჩენი სამი ვარიანტი („ჩართე“, „ზრდის სპირალი“, „პარტნიორობა“) არქივშია და კოდში არ გამოიყენება.

**წესები:** მინიმალური ზომები (ნიშანი 24px/8მმ, ჰორიზონტალური ლოკაპი 160px/40მმ, ვერტიკალური 120px/30მმ) და სუფთა სივრცე (= თავის წრის დიამეტრი) წინა სისტემიდან მოდის და საბოლოო ნიშანზე გადასამოწმებელია (§9). 48px-ზე ქვემოთ გრადიენტი და 3D ითიშება — გამოიყენება ბრტყელი ვერსია. 3D-ის ჩრდილები და გრადიენტები მხოლოდ ლოგოს ფაილშია და UI-ში ტოკენად არ გადადის.

**ფაილები:** `[საბოლოო ლოგოს ფაილის სახელი]`. საჭირო ნაკრები: SVG + PNG — ჰორიზონტალური, ვერტიკალური, mark, მონოქრომი, ინვერსიული, ბრტყელი (≤ 48px), favicon, ავატარი. არქივი: `meti-chartuloba-brand.zip`, `meti-chartuloba-logo-variants.zip`.

დიზაინის დაფებზე `logo` გადამრთველი ძველ ოთხ ვარიანტს აჩვენებს — ლოგოს გამოსახულება დაფებიდან არ აიღება.

- სტატიის ტექსტი სტრუქტურირებული ბლოკებია (`p`, `h2`, `h3`, `list`, `quote`, `image`, `link`; inline — მუქი, ბმული, `lang="en"` ფრაგმენტი), HTML სტრიქონი არსად ინახება.
- ტაქსონომიის id ლათინურია (`?category=career`), წარწერა i18n-შია; კონტენტის slug — ტრანსლიტერაცია. ფილტრები URL-შია: `category`, `q`, `year`, `series`, `sort`; ჩიპი — push, ძიება — 300ms debounce + replace.
- პიროვნული განვითარება: რჩეული „ჩვევა — 5 ნაბიჯი“ + ექვსი სერია = შვიდი თემა. ყდის `tone` მხოლოდ navy / navy-deep / petrol / orange / alt-ია; ყდა თემით არ იცვლება.
- თარიღი და დრო ყველგან `ka-GE` + `Asia/Tbilisi`. რიცხვის შემდეგ არსებითი მხოლობითშია („ნაპოვნია 5 სტატია“), plural-ის ლოგიკა არ არის. ინტერფეისის ტექსტი — `src/i18n/ka.js`; `en.js` — იგივე გასაღებები `[EN]` placeholder-ებით.
- შენახული სტატიები: `localStorage['mc-saved']` (slug-ების მასივი), ტაბებს შორის სინქრონი `storage` event-ით.
- კონტენტის შემოწმება (`validateContent`): dev-ში console.warn, F8-ში — ადმინის ჩეკლისტი, იგივე წესებით და ტექსტით; წარმოების bundle-ში არ ხვდება.
- ადმინი: `/admin/*`, ცალკე lazy chunk, `noindex` (robots.txt-ში არა); როლები — ადმინისტრატორი / რედაქტორი; რეგისტრაცია მოწვევის კოდით; frontend `adminAdapter`-ზე.
- ადმინის ფერები: სტატუსის ტინტები ამოღებულია (§2); მუქი warn #FFD166 → #FF8A4C; sidebar-ის ტექსტი #DCE6F1 → #EAF0F7 (14.7:1); „გასვლის“ ჩარჩო #3A5A80 (2.4:1) → #8FA3BC (6.5:1); რადიუსები სისტემის იერარქიაზე.
- გამოქვეყნების ბლოკერები: alt, სათაურების იერარქია, აღწერითი ბმულის ტექსტი, ვიდეოს სუბტიტრი + ტრანსკრიპტი + აუდიოაღწერა; ჟესტური ენის ვერსია — გაფრთხილება.
- slug: ქართული → ლათინური ეროვნული ტრანსლიტერაციით, აპოსტროფების გარეშე („ჩვევა — 5 ნაბიჯი“ → `chveva-5-nabiji`).
- ლოგო: „ერთად · სინერგია“ საბოლოოა (§4). `Logo` კომპონენტი მხოლოდ ამ ნიშანს იყენებს, `variant` prop-ის გარეშე; დანარჩენი სამი ვარიანტი არქივშია.
- React Router 8, Data Mode: `createBrowserRouter` + `lazy`, `RouterProvider` — `react-router/dom`. ESLint 9 (jsx-a11y ჯერ 10-ს არ უჭერს მხარს).
- თემა ქვეხეზეც მუშაობს (`[data-theme]`), მაგრამ კონტრასტის თემის შიგნით ჩადგმული თემა არ მოქმედებს.
