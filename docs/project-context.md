# პროექტის კონტექსტი — „მეტი ჩართულობა“

## 1. ორგანიზაცია

- **სრული სახელი:** მეტი ჩართულობა განვითარებისა და სოციალური ცვლილებებისთვის
- **სლოგანი:** „არასოდეს მისცე უფლება ფიზიკურ შეზღუდვებს შენი განვითარება შეაფერხოს!“
- **მისია:** შშმ პირების აქტიური ჩართვა საზოგადოებრივ ცხოვრებაში; პიროვნული და პროფესიული განვითარების, თვითრეალიზაციისა და სოციალური ცვლილებების მხარდაჭერა.
- **სამი მიმართულება:** ჩართულობა · განვითარება · სოციალური ცვლილება
- **ღირებულებები:** თავდაჯერებულობა, კრეატიულობა, გაბედულება, შეუპოვრობა, ცნობისმოყვარეობა, ზრდაზე ორიენტაცია
- **ბრენდის ხასიათი:** თავდაჯერებული, კრეატიული, გაბედული, ზრდაზე ორიენტირებული. არა — მოწყალე, პასიური, საქველმოქმედო.
- **ძირითადი აუდიტორია:** შშმ პირები და მათი ოჯახები; მეორეული — მოხალისეები, პარტნიორი კომპანიები, დონორები, მედია.

## 4. ლოგო

**საბოლოო ლოგო — „ერთად · სინერგია“.** გამოიყენება საიტის შვიდივე გვერდზე. **გამოსახულების წყარო — LogoSynergy დაფა** („ლოგო: ერთად · სინერგია“, კანვა §8). კოდის ფაილები ამ დაფის SVG-ებიდანაა ამოღებული; ლოგო თავიდან არ იხატება.

- საფუძველი — ვარიანტი „ერთად“: ხუთი ფიგურა მზის გარშემო, ფერხულის სიმეტრიით.
- შესრულება: ხუთი ნაჭერი — პაზლის ნაჭრები (კბილი R 8, ღრმული R 11.5), თავი პაზლის გარე ღილაკია (R 21); ნაჭრებს შორის 3.2px ღრეჩო; 3D = 9px ექსტრუზია ქვემოთ, ამოტვიფრვა ზემოთ, მუქი კონტური, დამატებითი ჩრდილის გარეშე. ნაჭრების რიგი: ნარინჯისფერი ზემოთ, შემდეგ საათის ისრით — ოქროსფერი, მწვანე, ცისფერ-ლურჯი, ლურჯი.
- სინერგია: ყოველი ნაწილიდან ენერგია ცენტრისკენ მიედინება (ტრაპეცია + სამი ჩევრონი); ოქროსფერ ჰაბში (R 29) — თეთრი ლოგარითმული სპირალი მუქ ოქროსფერ ბირთვზე (#946B11, 4.8:1).
- უარყოფილი შესრულება: LEGO-ბლოკები.
- დანარჩენი სამი ვარიანტი („ჩართე“, „ზრდის სპირალი“, „პარტნიორობა“) არქივშია და კოდში არ გამოიყენება.

## 6. ხელმისაწვდომობის გადაწყვეტები

- **თავსებადობის მენიუ** (ზედა ზოლში, ყველა გვერდზე და ადმინშიც): ხმოვანი რეჟიმი · შრიფტის ზომა · კონტრასტი · განლაგება (სტრიქონებს შორის მანძილი) · გასუფთავება. პარამეტრები ინახება `localStorage['mc-a11y']`-ში: `{ theme: 'light' | 'dark' | 'contrast', size: 100 | 125 | 150 | 175 | 200, spacing: boolean, voice: boolean }` (თემა არ არის → `prefers-color-scheme`). `<html>`-ზე: `data-theme`, `data-size`, `data-spacing="normal | wide"`. wide = WCAG 1.4.12: line-height × 1.2, ასო 0.12em, სიტყვა 0.16em, აბზაცი 2em. კონტრაქტი — `src/features/a11y/prefs.js`.
- **თავსებადობის მენიუ — ქცევა (F4):** არამოდალური პანელი ზედა ზოლის ღილაკის ქვეშ (`aria-expanded`, `aria-controls`); DOM-ში ღილაკს მოსდევს, ამიტომ Tab პირდაპირ პანელში შედის. იხურება Esc-ით (ფოკუსი ღილაკზე ბრუნდება), ✕-ით, გარეთ დაწკაპებით და ფოკუსის გასვლით (WCAG 2.4.11). პუნქტები: ხმოვანი რეჟიმი (`role="switch"`), შრიფტის ზომა −/+ (100 → 200, ბიჯი 25; ზღვარზე `aria-disabled`), კონტრასტი — რადიო-ჯგუფი სტანდარტული / მუქი / მაღალი, განლაგება (`role="switch"`), გასუფთავება (საცავის გასაღები იშლება, თემა OS-ს უბრუნდება). ყოველი ცვლილება `role="status"`-ით ცხადდება. `localStorage['mc-a11y']` = `{ size, theme?, spacing, voice }` (ხელით არჩეული თემის გარეშე `theme` არ იწერება); სხვა ჩანართში შეცვლა `storage` event-ით აისახება.
- **ხმოვანი რეჟიმი** `speechSynthesis`-ზეა. ქართული (`ka`) ხმა ბევრ ბრაუზერში არ არის — მაშინ პუნქტი გათიშულია (`aria-disabled`, ფოკუსს იღებს) და მიზეზს ტექსტით ხსნის, არ იმალება; ხმების სიის მოლოდინში — „ქართული ხმის შემოწმება…“ (≤ 2 წმ). ჩართვა კითხულობს `#main`-ის ტექსტს ბლოკებად, ჩართულ რეჟიმში — ყოველ ახალ გვერდსაც; Esc ნებისმიერ ადგილას აჩერებს (WCAG 1.4.2); გვერდის ჩატვირთვისას თავისით არ ირთვება.
- **გვერდზე გადასვლა (PageShell):** `document.title` = „{გვერდი} — მეტი ჩართულობა“ (მთავარზე — „მეტი ჩართულობა“), ფოკუსი გვერდის `<h1>`-ზე (hash-ით — სამიზნეზე), გვერდი ზემოთ — მყისიერად; „უკან“ პოზიციას აღადგენს. მხოლოდ query-ის ცვლილება (ფილტრი) ფოკუსს და სათაურს არ ცვლის. პირველ ჩატვირთვაზე ფოკუსი არ გადაიტანება.
- **რეჟიმი:** ღია / მუქი / მაღალი კონტრასტი, `prefers-color-scheme` + დამახსოვრებული არჩევანი; ღილაკი `aria-pressed`-ით; თემა პირველ რენდერამდე ედება `<html data-theme>`-ზე. სანამ თემა ხელით არ არის არჩეული, OS-ის ცვლილებას სესიის შუაშიც მიჰყვება.
- სამი თემა უკვე დაპროტოტიპებულია: სტანდარტული, მუქი, მაღალი კონტრასტი.
- სტატიები მოსასმენია; სლაიდებს აქვს ტექსტური (მარტივი ენის) ვერსია; ვიდეოებს — სუბტიტრები, ჟესტური ენა, აუდიოაღწერა, ტრანსკრიპტი.
- ფოკუსის სამშრიანი რგოლი, skip-link, `role="status"` ფილტრებსა და ფორმებზე, `aria-expanded` აკორდეონებზე.
- პროგრამებსა და ღონისძიებებს თან ახლავს ხელმისაწვდომობის აღწერა (ეტლით მისადგომობა, თარჯიმანი, ფორმატი).

- UI ნაკრები (F3): კომპონენტები `src/components/ui/`-შია, შესასვლელი `@/components/ui/index.js`; სტილები `components.css`-ში (`@layer components`, `mc-*` კლასები), ფერი მხოლოდ ტოკენით. მდგომარეობის ტოკენები: `--mc-hover`, `--mc-pressed`, `--mc-pressed-ink`, `--mc-card-border`, `--mc-band-bg`, `--mc-band-ink` (§2).
- ბარათი stretched-link-ია: ერთი Tab-გაჩერება სათაურის ბმულზე, ფოკუსის რგოლი მთელ ბარათზე (`:has`); DOM-ში სათაური პირველია, მედია და წარწერა ვიზუალურად ზემოთაა.
- მდგომარეობები `:hover / :focus-visible / :active / :disabled`; `/__kit` იგივეს `data-force`-ით აჩვენებს. გადაადგილება მხოლოდ `prefers-reduced-motion: no-preference`-ში.
- ხატულები: `src/assets/icons/icons.svg` (IconSet-ის 18 + UI-გლიფები) — ერთადერთი წყარო, `Icon` მას `?raw`-ით კითხულობს; აქცენტი ნაგულისხმევად `currentColor`, `accent` → `--mc-graphic` (ღია ფონზე მხოლოდ დეკორატიული).
- ფორმა: ლეიბლი ზემოთ, მინიშნება და შეცდომა ქვემოთ (`aria-describedby`), სავალდებულო — `required`, ხილულად ინიშნება „(არასავალდებულო)“; ჩამოსაშლელი — ნატიური `<select>`. ჩიპი, Select, RadioGroup იღებს `options()`-ის `{ id, label }`-ს.
- შენახვა: `aria-pressed`; ხატულიან ღილაკს მუდმივი სახელი აქვს („შენახვა: {სათაური}“), ლეიბლიანს — ხილული „შენახვა / შენახულია“ + სათაური (label-in-name).
- გარსი (F4): `RootLayout` = `PreferencesProvider` + `PageShell` + `ScrollRestoration`; გვერდის შეცდომა (`RouteError`) და 404 გარსის შიგნითაა, `RootError` — მხოლოდ გარსის ავარიისას. `createRoutes()` — ყოველ router-ს საკუთარი lazy-ობიექტები.
- გვერდის სათაური: როუტის `handle.title` (i18n-ის გასაღები) ან `usePageTitle()`; `<title>` გვერდში აღარ იწერება. გვერდი `<h1>`-ს პირველივე რენდერზე ხატავს.
- თავსებადობის პარამეტრები მხოლოდ `usePreferences()`-ით; `<html data-*>` და `mc-a11y` — მხოლოდ `PreferencesProvider` / mc-boot.
- ლოგოს ტონი თემით: ჰედერში ღია → `color`, მუქი → `inverse`, კონტრასტი → `mono`; ფუტერში `inverse` / `mono`. ჰედერში — ნიშანი (`layout="mark"`, 56 / 44px) + ცოცხალი ტექსტი „მეტი ჩართულობა“ (SiteHeader / HomeMobile დაფები), არა SVG ლოკაპი: ტექსტი შრიფტის ზომას მიჰყვება. ლოკაპის სიტყვიერი ნიშანი ცალკე lazy chunk-ია.
- ოქროსფერი #FFB81C გარსში მხოლოდ CTA-ზეა: თავსებადობის ღილაკის ჩარჩო და გახსნილი მდგომარეობა — ink (დაფაზე ოქროსფერი), პანელის ჩრდილი — `--mc-card-border`.
- ნავიგაცია ჰედერში 16px (დაფაზე 17): შვიდი ქართული პუნქტი 17px-ზე 827px-ია და სრული სახელით 1440-ზე 1329px > 1280 სჭირდება.
- „მუქი რეჟიმი“: ხატულა მუდმივად მთვარეა, მდგომარეობას ink-ის შევსება და `aria-pressed` აჩვენებს; კონტრასტის თემაში არ არის დაჭერილი, დაჭერა მუქზე გადაჰყავს.
- პროგრამული ფოკუსი (`<main>` skip-link-იდან, `<h1>` გადასვლისას) რგოლს არ აჩვენებს — ელემენტები არაინტერაქტიულია.
- `aria-current`: ზუსტ გვერდზე `page`, ქვეგვერდზე (`/articles/:slug`) — `true`.
- ორობითი პარამეტრი — UI ნაკრების `Switch` (`role="switch"`, მდგომარეობის ტექსტი `aria-hidden`); მიუწვდომელი — `aria-disabled` + ხილული მიზეზი. ზღვარზე მისული ღილაკი — `aria-disabled` (ფოკუსი არ იკარგება). IconButton-ის `aria-pressed` = ink-ის შევსება.
- ფუტერი: placeholder (`[ტელეფონი]`) და `url: null` ტექსტად რჩება, ბმულად — მხოლოდ `isPhone` / `isEmail` / URL-ის შემდეგ; სოციალური ქსელი ბმულის გარეშე — წყვეტილი ჩარჩო. სათაურები — `h2`.
- გრძელი ქართული სიტყვა გარსში (200%, 390px): `overflow-wrap: anywhere`; ვიწრო ზედა ზოლში თავსებადობის ღილაკის ხატულები ქრება (container query).
