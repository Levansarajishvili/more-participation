# პროექტის კონტექსტი — „მეტი ჩართულობა“

## 1. ორგანიზაცია

- **სრული სახელი:** მეტი ჩართულობა განვითარებისა და სოციალური ცვლილებებისთვის
- **სლოგანი:** „არასოდეს მისცე უფლება ფიზიკურ შეზღუდვებს შენი განვითარება შეაფერხოს!“
- **მისია:** შშმ პირების აქტიური ჩართვა საზოგადოებრივ ცხოვრებაში; პიროვნული და პროფესიული განვითარების, თვითრეალიზაციისა და სოციალური ცვლილებების მხარდაჭერა.
- **სამი მიმართულება:** ჩართულობა · განვითარება · სოციალური ცვლილება
- **ღირებულებები:** თავდაჯერებულობა, კრეატიულობა, გაბედულება, შეუპოვრობა, ცნობისმოყვარეობა, ზრდაზე ორიენტაცია
- **ბრენდის ხასიათი:** თავდაჯერებული, კრეატიული, გაბედული, ზრდაზე ორიენტირებული. არა — მოწყალე, პასიური, საქველმოქმედო.
- **ძირითადი აუდიტორია:** შშმ პირები და მათი ოჯახები; მეორეული — მოხალისეები, პარტნიორი კომპანიები, დონორები, მედია.

## 6. ხელმისაწვდომობის გადაწყვეტები

- **თავსებადობის მენიუ** (ზედა ზოლში, ყველა გვერდზე და ადმინშიც): ხმოვანი რეჟიმი · შრიფტის ზომა · კონტრასტი · განლაგება (სტრიქონებს შორის მანძილი) · გასუფთავება. პარამეტრები ინახება `localStorage['mc-a11y']`-ში: `{ theme: 'light' | 'dark' | 'contrast', size: 100 | 125 | 150 | 175 | 200, spacing: boolean, voice: boolean }` (თემა არ არის → `prefers-color-scheme`). `<html>`-ზე: `data-theme`, `data-size`, `data-spacing="normal | wide"`. wide = WCAG 1.4.12: line-height × 1.2, ასო 0.12em, სიტყვა 0.16em, აბზაცი 2em. კონტრაქტი — `src/features/a11y/prefs.js`.
- **თავსებადობის მენიუ — ქცევა (F4):** არამოდალური პანელი ზედა ზოლის ღილაკის ქვეშ (`aria-expanded`, `aria-controls`); DOM-ში ღილაკს მოსდევს, ამიტომ Tab პირდაპირ პანელში შედის. იხურება Esc-ით (ფოკუსი ღილაკზე ბრუნდება), ✕-ით, გარეთ დაწკაპებით და ფოკუსის გასვლით (WCAG 2.4.11). პუნქტები: ხმოვანი რეჟიმი (`role="switch"`), შრიფტის ზომა −/+ (100 → 200, ბიჯი 25; ზღვარზე `aria-disabled`), კონტრასტი — რადიო-ჯგუფი სტანდარტული / მუქი / მაღალი, განლაგება (`role="switch"`), გასუფთავება (საცავის გასაღები იშლება, თემა OS-ს უბრუნდება). ყოველი ცვლილება `role="status"`-ით ცხადდება. `localStorage['mc-a11y']` = `{ size, theme?, spacing, voice }` (ხელით არჩეული თემის გარეშე `theme` არ იწერება); სხვა ჩანართში შეცვლა `storage` event-ით აისახება.
- **ხმოვანი რეჟიმი** `speechSynthesis`-ზეა. ქართული (`ka`) ხმა ბევრ ბრაუზერში არ არის — მაშინ პუნქტი გათიშულია (`aria-disabled`, ფოკუსს იღებს) და მიზეზს ტექსტით ხსნის, არ იმალება; ხმების სიის მოლოდინში — „ქართული ხმის შემოწმება…“ (≤ 2 წმ). ჩართვა კითხულობს `#main`-ის ტექსტს ბლოკებად, ჩართულ რეჟიმში — ყოველ ახალ გვერდსაც; Esc ნებისმიერ ადგილას აჩერებს (WCAG 1.4.2); გვერდის ჩატვირთვისას თავისით არ ირთვება.

## 10. გადაწყვეტილებები

- სტეკი: Vite + React + React Router (library mode) + Tailwind v4 (CSS-first, `@theme`), JavaScript (JSX) + JSDoc. Tailwind-ის ნაგულისხმევი პალიტრა გათიშულია — მხოლოდ ტოკენები.
- URL-ები ლათინურად (§5), რომ გაზიარებულ ბმულში percent-encoding არ გამოჩნდეს.
- თემები: `[data-theme="light | dark | contrast"]`; პირველ რენდერამდე inline script `mc-a11y`-დან.
- ჰეროს CTA „ჩაერთე“ ბრუნდება — სამი შესასვლელი ნავიგაციაა და არა ქმედება; ჩართვა პირველ ეკრანზე ერთი ოქროსფერი ღილაკით ჩანს.
- სლაიდერი: ← → Home End, მხოლოდ სლაიდერში ფოკუსისას (WAI-ARIA APG carousel, ავტოდაკვრის გარეშე).
- ვიდეო 390px-ზე: მთავარი რიგი (დაკვრა, პროგრესი, CC, სრული ეკრანი) + „მეტი“ (ჟესტური ენა, აუდიოაღწერა, ტრანსკრიპტი, სიჩქარე). YouTube-ის ვიდეოზე (F10): ჟესტური ენა არ არის — „მეტში“ აუდიოაღწერა, ხმა, ტრანსკრიპტი, სიჩქარე.
- ჰედერი < 1200px: ჰამბურგერი, `aria-expanded`, `aria-controls`, Esc ხურავს და ფოკუსს ღილაკზე აბრუნებს; გახსნილი პანელისას ფონი `inert`-ია, Tab ციკლავს ჰამბურგერსა და პანელს შორის. ზღვარი ზოლის რეალურ სიგანესა და rem-ზეა (`useShellLayout`: desktop ≥ 65rem, wide ≥ 78rem, გაშლილ ინტერვალებზე × 1.2) — 100%-ზე ეს ზუსტად 1200 / 1440px-ია, 125%+-ზე 1440px-ის კონტეინერში ჰამბურგერი რჩება. 1200–1439px-ზე სახელი ვიზუალურად დამალულია (ნიშანი + ეკრანის მკითხველისთვის სახელი).
- შენახვის შევსება: `--mc-ink` (§7).
- მაღალი კონტრასტის თემა: §2.
- კონტენტი adapter-ის უკანაა: ახლა mock `[ფრჩხილებიანი]` მონაცემებით, მერე backend ან CMS. მოდელი ადმინის რედაქტორის ველებს 1:1 იმეორებს.
- კონტენტის ერთადერთი შესასვლელი — `src/content/adapter.js` (`list*` / `get*` / `subscribe` / `confirmSubscription` / `unsubscribe` / `sendContact`); ყველა ფუნქცია Promise-ს აბრუნებს, შეცდომა — `ContentError { code, message, fields }` მიმდინარე ენაზე. HTTP adapter-ი (`src/content/http.js`, B6) იმავე `ContentAdapter` კონტრაქტს აკმაყოფილებს და `VITE_CONTENT_API`-ით ირთვება; mock ცალკე lazy chunk-ია და env-ის გარეშე ის მუშაობს (წარმოებაში — B7).
- mock-ის წესი (ტესტით დაცული): ყოველი წასაკითხი ტექსტი `[ფრჩხილებშია]`; მედიის `src` და გარე URL — `null` (UI ჩანაცვლების ჩარჩოს ან გათიშულ ღილაკს ხატავს); ISO თარიღები სინთეზურია და მიმდინარე დროზეა მიბმული.

### Backend-ის წესები (არადათმობადი)

- სესია მხოლოდ httpOnly + Secure + SameSite cookie-შია; token JS-ში და localStorage-ში არასოდეს; CSRF — double-submit (`__Host-mc-csrf` → `X-CSRF-Token`, token სესიაზე მიბმული); cookie-ები `__Host-` პრეფიქსით (B3).
- ცვლილების მოთხოვნა სხვა საიტიდან (`Sec-Fetch-Site: cross-site | same-site`) → 403; ნაგულისხმევი ანგარიში და პაროლი არ არსებობს (პირველი ადმინისტრატორი — `server:create-admin`).
- ყოველი endpoint-ის შემავალი მონაცემი სქემით მოწმდება; უცნობი ველი უარყოფილია.
- გამოქვეყნების ბლოკერი სერვერზეც მოწმდება — იგივე `validate.js` (ქართული და ინგლისური ვერსია, საერთო `src/content/checks.js`-ით); frontend-ის შემოწმება მხოლოდ UX-ია.
- როლის უფლება სერვერზე მოწმდება (`permissions.js`-ის ცხრილით) → 403.
- შესვლა: უცნობი ელფოსტა და არასწორი პაროლი — ერთი და იგივე პასუხი და დრო; rate limit შესვლაზე, რეგისტრაციაზე და საჯარო ფორმებზე (CAPTCHA-ს გარეშე).
- დიაგნოზი და ჯანმრთელობის მონაცემი არ გროვდება — მხოლოდ მხარდაჭერის საჭიროება (ტექსტი), როგორც ფორმაშია; ლოგებში პერსონალური მონაცემი არ ჩაიწერება.
- `/admin` და `/en/admin` — `X-Robots-Tag: noindex, nofollow`; mock adapter-ი წარმოებაში გამორთულია.
- ერთი origin: CORS header-ები არ იგზავნება; `Referrer-Policy: strict-origin-when-cross-origin` (`@fastify/helmet`-ის `no-referrer` YouTube-ის ჩაშენებას არღვევს).
- მისამართები, connection string და გასაღებები (`CONTACT_INBOX`, `MONGODB_URI`, R2, Resend) — მხოლოდ env-ში; `.env.example` — placeholder-ებით.
